# Movie Finder
A responsive movie discovery web application that allows users to search for movies, explore genres, watch trailers and check streaming availability through real-time movie data.
The project was built to practice working with external APIs, asynchronous JavaScript, dynamic interfaces, filtering systems and API security while creating a complete user-facing web application.

## Live Website
View Movie Finder here --> https://movie-finder-three-alpha.vercel.app/

## Features
- Search for movies by title
- Browse and filter movies by genre
- View movie information and details
- Watch available movie trailers
- Check streaming/platform availability
- Discover random movies
- Explore popular movies
- Add movies to a personal watchlist
- Responsive interface for different screen sizes
- Real-time movie information retrieved through an external API
- Secure API key handling using a serverless backend

## Technologies Used

### HTML5
Used to create the structure and content of the website.

### CSS3
Used for the responsive layout, styling, animations, interface components and Y2K/retro-inspired visual design.

### JavaScript
Used for the main application logic, including:

- API requests
- Search functionality
- Movie filtering
- Dynamic movie rendering
- Watchlist functionality
- Trailer retrieval
- Streaming provider information
- User interactions

### TMDB API
Movie information is retrieved using **The Movie Database (TMDB) API**.

The API provides data including:

- Movie titles
- Posters
- Descriptions
- Genres
- Ratings
- Release dates
- Trailers
- Streaming provider information



## 📁 Project Structure
### `index.html`
Contains the main structure and interface of the website.

### `styles.css`
Contains the website's styling, responsive design, animations, and visual theme.

### `script.js`
Handles movie searches, API requests, filtering, watchlists, trailers, streaming information, and dynamic content.

### `api/movies.js`
Serverless API function that securely communicates with TMDB using the API key stored in Vercel.
